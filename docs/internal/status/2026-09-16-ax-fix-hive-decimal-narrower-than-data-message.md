Max is 999.99`: Glue declares the column `decimal(5,2)`, the Parquet file (Trino-written) carries `decimal(10,2)`, one row of 13,816 exceeds the declaration. SQE reads at the declared type, as Athena does, so that row fails every statement touching the column. Decided against reading the footer to let the file's type win: it would add a storage round trip per table to the crawl we just made Glue-only, and make the same column answer differently in SQE and Athena. The column name itself is not in Arrow's message; the hook that could add it is DataFusion 55's `PhysicalExprAdapterFactory` on the file scan (`SchemaAdapter` is gone), which is where a per-column wrapped cast would live if the hint proves insufficient.
