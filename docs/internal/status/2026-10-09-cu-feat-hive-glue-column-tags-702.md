**STATUS 2026-10-09 (cu): a Glue column tag reaches the Hive tag policies (`feat/hive-glue-column-tags-702`, #702).** The Glue mapping dropped each column's `Parameters` and set an empty SQE block, so a column tagged in Glue read as untagged and its tag mask never applied. `HiveManifest::column_tags()` is now the one reader, and it takes the union of three places a tag can live: the sidecar `sqe.column_tags` block, a `sqe.column-tags` table parameter (the JSON object the Iceberg path reads), and each column's and partition key's own `sqe.column-tags` parameter (a JSON array, where Glue carries it). It is a union, never a precedence, so a tag can only add a mask. A value that does not parse is unknown tag state: `HiveTagSource` reports it as unknown (the rewriter denies) and the DDL listing path denies too, so a listing never shows what a `SELECT` refuses. Tests: Glue mapping and manifest unit tests plus `hive_tag_source_test`. **NEXT:** a live Glue read of a tagged column under Ranger.
