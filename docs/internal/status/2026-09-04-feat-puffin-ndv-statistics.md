**STATUS 2026-09-04: Puffin NDV statistics consumer implemented behind two flags on `feat/puffin-ndv-statistics`; registry arm measured negative at SF1.**

The DataFusion 55 handover left Phase 6 (statistics adoption) as the next action. The worktree it described as empty held the consumer half uncommitted under `cargo fmt` noise; the real changes are now committed. `PuffinNdvCache` reads the `ndv` blob property straight from the snapshot `StatisticsFile` metadata (no sidecar fetch), `SqeTableProvider::scan_with_args` answers `StatisticsRequest::DistinctCount` as inexact column statistics, and `PuffinStatisticsRequestRule` asks for them on every projected scan column. `query.puffin_statistics` (env `SQE_QUERY__PUFFIN_STATISTICS`) turns that on; a separate `query.statistics_registry` flips `datafusion.optimizer.use_statistics_registry`. Both default false.

Two bugs surfaced by checking the warehouse instead of the logs. A full bench load produced zero `.stats` files: the coordinator routes CTAS and INSERT through the streaming handlers, and only the buffered handlers called the sidecar emitter, so the Phase F writer had never run on the default path. `ThetaSketchAccumulator` now taps the batch stream. Then the first sidecars showed `ndv = 0` on Decimal128 and Date32 (admitted as sketchable, no handler, one WARN per batch) and no blob at all for strings, because DataFusion 55 reads Parquet strings as `Utf8View`. All handled; a unit test asserts every admitted type yields an estimate. Orders at SF0.1 now reads o_orderkey 148715 (true 150000), o_clerk 1000 (exact).

Evidence in `docs/evidence/perf/puffin-ndv-ab-2026-09-04.md`. SF0.1 Trino compare with everything on: TPC-H 22/22, SSB 11/13 (known vacuous pair). SF1 plans: the NDV-only arm is identical to baseline except q17; the registry arm flips the hash build onto lineitem (or its aggregate) in q03/q05/q17/q18/q21 and reverses the runtime-filter direction, which is the opposite of what `dim_build_swap` and `star_schema_reorder` do on purpose. Counterbalanced timing: q17 1.40x slower in both rounds, q03/q05 1.23x; the NDV-only arm is runtime-neutral within this box's 20-40% noise. Verdict: registry stays off, NDV requests are safe but earn nothing yet, `write.puffin.stats` default stays off until a consumer pays for the write.
