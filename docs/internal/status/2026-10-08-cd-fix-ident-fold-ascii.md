**STATUS 2026-10-08 (cd): unquoted identifiers fold ASCII letters only (`fix/ident-fold-ascii`, #337).** DataFusion lowercases only the ASCII letters of an unquoted identifier, but DDL (`fold_unquoted_ident`) and the policy-predicate column stub used Unicode lowercase. `CREATE TABLE t (ÉTAT INT)` therefore stored `état`, and `SELECT ÉTAT` looked up `État` and missed. A row filter naming `ÉTAT` failed to parse the same way. Both now use `to_ascii_lowercase`. A property test uses DataFusion's own `IdentNormalizer` as the oracle for any quoted or unquoted name.
