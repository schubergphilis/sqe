**STATUS 2026-10-09 (cr): the grant option is admin-only (`fix/grant-option-chaining-817`, #817).** `GRANT ... WITH GRANT OPTION` now needs an engine admin role under either `grant_authority`. The coordinator checks it in `handle_grant`, and the Ranger backend refuses `with_grant_option` from a non-admin grantor with a 403 before any request, using the new `GrantStatement.grantor_is_admin`. A delegate can still grant the privilege onward, but not the grant option, so ownership no longer passes along a chain of delegates. The book's "no `WITH GRANT OPTION`" gap lines now describe this. **Open:** the live-Ranger case `a_delegated_owner_grants_on_their_own_table_without_an_admin_role` was extended but needs a `make test-access-control` run.
