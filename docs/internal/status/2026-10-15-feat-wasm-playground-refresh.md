**STATUS 2026-10-15: SQE Playground lands on main, refreshed (`feat/wasm-playground-refresh`).**

`playground/` compiles DataFusion 55 to `wasm32-unknown-unknown` and runs SQL in a browser tab against parquet and CSV over HTTP or S3, and against copy-on-write Iceberg tables through `src/iceberg.rs`, which reads `metadata.json`, the manifest list and the manifests directly because iceberg-rust cannot build for wasm32 (opendal's `Access` futures carry no `Send` bound). The work sat on `feat/wasm-playground` since 2026-09-16, 820 commits behind main; its four commits each edited the now-frozen `nextsteps.md`, so the tree was carried over onto main rather than rebased. The original branch's findings live in `playground/README.md` (CORS `ExposeHeaders: content-range`, HTTP Range, WebDAV PROPFIND, the `chrono` `wasmbind` and `getrandom` traps).

What the refresh changed:

- `run_sql` and `explain` stream the plan and drop the stream once one row past the 2,000-row cap arrives, which cancels the scan. Collecting first meant `SELECT *` without a `LIMIT` on the 2 GB dataset pulled every byte to show 2,000 rows. Measured in Chrome: a 100-million-row `generate_series` returns in 3 ms. A truncated result no longer knows its total, so the status line reads `first 2000`. Empty results now carry their column headers.
- Lockfile: `object_store` patched to `vendor/object_store` as the root does (quick-xml 0.39.4 -> 0.41.0, RUSTSEC-2026-0194/0195), and rustls 0.23.43 -> 0.23.46 (RUSTSEC-2026-0285/0346/0348/0349). The crate is outside the workspace, so it inherits neither the root patch nor the root lockfile; `cargo deny check advisories` against it is clean.
- Toolchain pin 1.98.0 -> 1.99.0, matching the root.
- License gate: syft reads `playground/Cargo.lock`, so `sqe-playground@0.1.0` is in the SBOM, but the shared `sbom-license-from-cargo.py` only reads manifests at fixed paths and `aikido-license-policy --strict` failed it with "license evidence missing". aikido !223 adds `AIKIDO_SBOM_LICENSE_MANIFESTS`; `aikido-sbom` sets it to `playground/Cargo.toml`, and the aikido include and `AIKIDO_SHARED_REF` move to that commit.
- Six host-side tests for the Iceberg reader, three of them end to end on the bundled fixture: the current snapshot reads 6 rows from 2 files, the previous `metadata.json` 3 rows from 1, and the empty first version is refused.
- Fixed: the zero-column `register` error carried runs of spaces from a broken string continuation; the module doc still said "there is no Iceberg"; the README said AWS endpoints serve no CORS headers while its own later section measured that they do.

Verified: `./build.sh` (25 MB raw, 6.8 MB gzip, unchanged), host tests 6/6, wasm32 clippy clean, and in Chrome via Playwright: Iceberg fixture `count(*)` = 6, local parquet and CSV registration, EXPLAIN, a missing directory fails with DataFusion's "No files found", exactly 2,000 rows is not marked truncated, 5 M rows through the UI shows `first 2000`. No CI job builds `playground/`.

**NEXT:** an Iceberg REST catalog client (bearer token for Polaris and Snowflake Open Catalog, SigV4 for S3 Tables) feeding `loadTable` metadata into the reader; then merge-on-read position deletes (SQE defaults to copy-on-write, so this matters mostly for tables written by other engines) and partition pruning from the manifest statistics that are parsed and discarded.
