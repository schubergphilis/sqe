**STATUS 2026-09-14 (ae): SQE connects to RustFS S3 Tables (`feat/rest-catalog-client-side-sigv4`, stacked on the #382 MR).** Asked whether SQE can talk to the catalog in fdass/iceberg-rustfs (RustFS 1.0.0-rc.6 with its built-in Iceberg REST catalog). Out of the box it could not, for three separate reasons found one behind the other against a live container: RustFS requires SigV4 (service `s3`) but advertises nothing in `/v1/config`, so the vendored client sent unsigned requests (403 "Signature is required"); once signed, RustFS demanded the S3 payload hash header (400 "missing header: x-amz-content-sha256"), which the vendored signer never set; and SQE's own raw REST helper (`authorize_table_access` HEAD, `rest_request`, `fetch_table_etag_inner`) bypasses the vendored authenticator and sent `Authorization: Bearer ` with the empty bearer (400 "invalid header: authorization", surfaced as "Authorization check failed for table"). Fixes: `CatalogAuthConfig::Aws { signing_name, signing_region }` maps to the `rest.sigv4-enabled` / `rest.signing-*` props (`client_side_sigv4_props`, region defaults to `[storage] s3_region`); the vendored `SigV4Signer` is public, signs an `http::HeaderMap` (so the reqwest 0.13 raw path and the reqwest 0.12 vendored client share it), sets `PayloadChecksumKind::XAmzSha256` when the service is `s3`, and takes static keys from `s3.access-key-id` / `s3.secret-access-key` before the SDK chain; `SessionCatalog` builds the same signer from the same props and `authenticate_raw_request` signs or bearers every raw call. Live: SHOW SCHEMAS, CREATE SCHEMA, CREATE TABLE, INSERT, SELECT, CTAS, DROP TABLE all clean against `rustfs/rustfs:1.0.0-rc.6`. New `quickstart/rustfs-s3tables/` (compose with bucket-init and the `PUT /iceberg/v1/buckets/warehouse` enable call, sqe.toml, queries, run.sh --check, book page, index rows). Not visible to the raw path by design: SigV4 a server only advertises via `/v1/config` (Glue, Amazon S3 Tables keep the bearer on raw calls as before; the vendored client signs). Verified: clippy with tests on core, auth, catalog; the four sigv4 unit tests; config (273) and per_catalog (7) suites; slim `--no-default-features --features rest` check of sqe-catalog.
